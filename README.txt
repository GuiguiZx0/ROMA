# NOVA — Portfólio de Design & Web

Site demonstrativo para uma mini empresa/freelancer de design e criação de sites.

## Como usar
1. Extraia a pasta.
2. Abra `index.html` no navegador.
3. Edite textos, projetos e o e-mail no `index.html`.
4. Personalize cores, tamanhos e layouts no `style.css`.

## Arquivos
- index.html — estrutura do site
- style.css — visual e responsividade
- script.js — menu mobile, animações e efeitos

Os projetos mostrados são exemplos/conceitos e devem ser substituídos pelos seus trabalhos reais.
